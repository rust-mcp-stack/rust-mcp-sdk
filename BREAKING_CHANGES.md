# Breaking Changes

Breaking changes are documented per version in the migration guides and the
auto-generated changelog.

## Where to look

- **[Migration guides](./UPGRADING.md)** — step-by-step upgrade instructions
  between major/breaking versions. Each guide lists every removed API, rename,
  and its replacement.
- **[CHANGELOG.md](./CHANGELOG.md)** — auto-generated per-release changelog with
  a `⚠ BREAKING CHANGES` section for each version.

## Current migration

For the current major bump (MCP 2025-11-25 → 2026-07-28), see the
[v1.x to v2.0.0 migration guide](./doc/migration/v1.x-to-v2.0.0.md).
