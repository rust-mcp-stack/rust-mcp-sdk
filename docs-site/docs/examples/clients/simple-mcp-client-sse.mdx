Location: `crates/rust-mcp-sdk/examples/simple-mcp-client-sse.rs`

Connects to an MCP server via SSE transport.

```bash
cargo run --example simple-mcp-client-sse -p rust-mcp-sdk
```

Requires a running server with `sse_support: true`.
