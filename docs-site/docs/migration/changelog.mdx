## 1.0.0

- First stable release
- All crates at v1.0.0
- 100% MCP conformance (40/40 server, 254/254 client)
- Protocol 2025-11-25
- Typo fixes in public API (breaking renames - old names removed, update call sites)
- Dead code removal
- CI hardening
- Handler traits remain open

## 0.10.x

- Pre-release versions leading to 1.0.0
- Streamable HTTP transport
- OAuth authentication framework
- MCP Tasks support
- Message Observer pattern
- DNS rebinding protection

## 0.9.x

- Initial releases
- Stdio transport
- ServerHandler / ClientHandler traits
- Basic tool and resource support
