# Rust MCP SDK

A high-performance, asynchronous Rust toolkit for building **MCP servers** and **MCP clients** - with 100% conformance to the official MCP test suites.

[![crates.io](https://img.shields.io/crates/v/rust-mcp-sdk?style=for-the-badge&logo=rust&color=FE965D)](https://crates.io/crates/rust-mcp-sdk)
[![docs.rs](https://img.shields.io/badge/docs.rs-rust_mcp_SDK-0ECDAB?style=for-the-badge&logo=docs.rs)](https://docs.rs/rust-mcp-sdk)


## What is MCP?

The [Model Context Protocol](https://modelcontextprotocol.io/) (MCP) is an open standard for connecting LLM applications to tools and data. It is a uniform way for AI applications (like Claude, ChatGPT, or your own agent) to discover and use capabilities you expose.

With MCP you can build:

- **Servers** that expose *tools* (functions the LLM can call), *resources* (data the LLM can read), and *prompts* (reusable interaction templates)
- **Clients** that connect to servers, discover their capabilities, and invoke them

**rust-mcp-sdk** handles the protocol, transports, session management, authentication, and schema generation - you focus on your application logic.

## Why rust-mcp-sdk?

| | |
|---|---|
| ✅ | **100% MCP Conformance** - passes all official server and client conformance tests |
| ✅ | **Latest protocol** - MCP spec `2025-11-25` |
| ✅ | **All transports** - Stdio, Streamable HTTP, and backward-compatible SSE |
| ✅ | **Framework agnostic** - native Axum & Actix-web integrations, plus BYO-server mode |
| ✅ | **Procedural macros** - `mcp_tool`, `tool_box!`, `mcp_elicit` generate schemas from your structs |
| ✅ | **OAuth 2.1** - server and client auth with DCR, PKCE, token refresh, and ready-made providers |
| ✅ | **Production ready** - DNS rebinding protection, resumability, health checks, tasks, telemetry hooks |
