## v0.10.x → v1.0.0

The jump from v0.10.x to v1.0.0 is the first stable release.

See the [v0.10 to v1.0 migration guide](/docs/migration/v0.10-to-v1.0).

## v0.9.x → v0.10.x

If you are still on v0.9.x, refer to the [v0.9 to v0.10 migration guide](/docs/migration/v0.9-to-v0.10).

All crates are now at v1.0.0 together - `rust-mcp-sdk`, `rust-mcp-schema`, `rust-mcp-transport`, `rust-mcp-macros`, `rust-mcp-axum`, `rust-mcp-actix`, and `rust-mcp-extra`.
